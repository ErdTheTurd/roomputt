# Roomputt

Website for Roomputt.

Roomputt is an upcoming Apple Vision Pro app: mini golf on your living-room floor. The couch is a bank, the coffee table is an obstacle, and strokes sit on a scorecard. It is in development and not released.

The site is static. Open `index.html` in a browser, or host this folder with GitHub Pages or any static host. There is no build step.
